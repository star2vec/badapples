## 2026-09-29 Is herding social? Single decisions on the base model, the pilot (user's brief; plan reviewed, amended and approved)
Question (user's): in the game villagers cast more when the others' messages mention casting; do the same words from a non-social source move the model as much? No training, the base model only. Single-decision prompts from real generation-zero villager situations (runs/copying/play_g0, villagers s0 to s2, 30 days), the same situations in every condition; only the report about the last round changes; the golden fish line of the last round says none; the system prompt is the game's for that agent; sampling as in the game (temperature 1, top_p 1, 256 tokens, the game's parser); m of 7 report lines say cast. Pilot: peers at 0 against 7, stop if there is no clear herding. Main run (not run): peers, printer, bots, independence stated, real messages at 8 levels and no report, 100 situations each.

(3) Not shown: whether the source matters for messages.
