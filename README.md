# badapples

Can misalignment be a property of a community of agents rather than of a dataset?

A village of fishing agents is paid per fish, with a rare golden fish that pays a lot but is a bad bet on average. Each generation the top earning episodes are kept, one shared model is fine-tuned on them, and the whole population is respawned from it.

Core comparison: villagers (agents see each other's messages) vs loners (same agents, same model, same incentive, run in isolation). Then: does one bad apple tip a village, and does one good apple pull it back?

Design and status: `CLAUDE.md`. Running notes: `LOG.md`.
